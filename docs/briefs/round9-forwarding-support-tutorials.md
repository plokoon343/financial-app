## Part A: Email forwarding in under a minute
**A1. Bank sender list (data, not code).** (1) Mine our own data: from inbound emails already parsed successfully, list every distinct sender address and display name by bank, with counts (addresses only, no user data). (3) Only alert senders count: OTP, marketing and newsletter senders are "exclude". (4) Auto-grow: an unknown sender whose email parses as a bank alert 3+ times across different users is added "unverified" to an admin review queue. **A3. Auto-confirm Gmail's forwarding check:** extend the existing detection (see above): show "Your Gmail code is 123456. Paste it in Gmail." with copy button + push; never act on the user's behalf; log arrival; same for Outlook.

Recommendation: not worth pursuing yet.
